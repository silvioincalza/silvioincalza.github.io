# Working in this repository

- Content lives in `content/site.json`; pages are generated by `scripts/build.py`. Never commit `_site/`.
- Write as Silvio writes: plain English, short sentences, no marketing words, no invented numbers.
- A summary in `site.json` states only what its ADR in helper2.ai says.
- Every change reaches `main` through a pull request opened with `gh` from Silvio's machine. Silvio reviews and
  merges it. Never merge, never push to `main`.
- Never add AI attribution, "Generated with" footers or Co-Authored-By lines to commits, PRs or files.
- Notes, plans and reviews go in the git-ignored `.private/` folder.
